**Goal:** *Rewind to here* on a user message removes that message and everything after it, from both the transcript and the provider's conversation, and puts the message back in the composer to edit. With Claude, you can also restore files to how they were before that message.

**Architecture:** Turn items carry provider references:
- **`promptRef`**, on a turn's started and ended items alike (they share an id, so the transcript keeps only the latest), is the provider's id for the prompt that started it:
  - **Claude:** the `uuid` AgentDeck sets on the streamed `SDKUserMessage`.
  - **Codex:** the turn id.
- **`ref`**, on an ended turn, is the provider's resume point:
  - **Claude:** the uuid of the last main-chain message in the turn.

`ProviderSession.rewind({ prompt, keep, files })` acts on these references:
- **Codex:** calls `thread/revert { beforeTurnId: prompt }` on the live thread.
- **Claude:**
  - optionally restores files with `rewindFiles(prompt)`; file checkpointing is now enabled for every Claude session;
  - asks for a restart at `keep`.

When a provider asks for a restart, the session manager:
1. stops the CLI;
2. stores `record.resumeAt`;
3. on the next open passes `resumeAt`. Claude turns that into `resume`, `resumeSessionAt`, `forkSession: true` and a new `sessionId`.

Rewinding the first message starts a new provider session. The manager rewrites the journal without the removed items and sends a fresh snapshot.

Verified in the Agent SDK types:
- `SDKUserMessage.uuid`;
- `Options.resumeSessionAt`, which accepts any chain entry: fork at the kept turn's last entry;
- `Options.forkSession`, together with `sessionId`, gives a custom id to the fork;
- `Options.enableFileCheckpointing`;
- `Query.rewindFiles(userMessageId)`.

In the Codex schema: `thread/revert { threadId, beforeTurnId }`.

  /**
   * Removes a user message and everything after it, here and in the provider; returns the message's parts so the
   * user can edit and resend them. `files` also restores files where the provider supports it.
   */
  async rewind(id: string, userItemId: string, files: boolean): Promise<PromptPart[]> {
    const live = this.load(id)
    if (isBusy(live.status)) throw new Error('Stop the running turn before rewinding.')
    const items = [...live.items.values()]
    const index = items.findIndex((item) => item.id === userItemId)
    const target = items[index]
    if (index < 0 || target.kind !== 'message' || target.role !== 'user') throw new Error('Rewind needs a message you sent.')
    const kept = items.slice(0, index)
    // A turn's started and ended items share an id, so the transcript holds its latest state; both carry promptRef.
    const started = items.slice(index).find((item): item is TurnItem => item.kind === 'turn')
    const keep = kept.findLast((item): item is TurnItem => item.kind === 'turn' && item.ref !== undefined)?.ref
    if (live.record.hasTurns) {
      const session = live.session ?? (await this.connect(live))
      if (!session.rewind) throw new Error('This provider cannot rewind.')
      const { restart } = await session.rewind({ prompt: started?.promptRef, keep, files })
      if (restart) {
        await this.stop(id)
        this.setStatus(live, 'idle')
        if (restart.resumeAt) live.record.resumeAt = restart.resumeAt
        else {
          live.record.hasTurns = false
          delete live.record.nativeId
        }
      }
    }
    live.journal.flush()
    live.items = new Map(kept.map((item) => [item.id, item]))
    Journal.write(this.journalPath(id), kept)
    delete live.record.laneSeen
    await this.save(live)
    const snapshot: SessionEvent = { type: 'snapshot', record: live.record, status: live.status, items: kept, queue: [...live.queue] }
    for (const subscriber of live.subscribers) subscriber(snapshot)
    this.changed.fire()
    return target.parts
  }
```

  (import `TurnItem`; if `live.items` is `readonly`, make it assignable; if `stop` already sets a status the test does not expect, keep `this.setStatus(live, 'idle')` after it; report anything you had to adjust.)

// Live check: after rewinding the second message, the agent no longer knows it.
import { mkdtempSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { join } from 'node:path'
import type { PromptPart, SessionItem } from '../src/core/types'
import { captureEnv } from '../src/env'
import { providers } from '../src/providers/registry'
import { SessionManager } from '../src/sessions/manager'
import { SessionStore } from '../src/sessions/store'
import { MemoryMemento } from '../test/memory-memento'

async function main(): Promise<void> {
  const providerId = process.argv[2] ?? 'claude'
  const cwd = mkdtempSync(join(tmpdir(), 'agentdeck-rewind-'))
  const env = await captureEnv()
  const manager = new SessionManager({ providers, store: new SessionStore(new MemoryMemento()), journalDir: join(cwd, '.journal'), cwd, env: async () => env })
  const { id } = await manager.create(providerId)
  let items: SessionItem[] = []
  manager.subscribe(id, (event) => {
    if (event.type === 'snapshot') items = event.items
    if (event.type === 'item') items = [...items.filter((item) => item.id !== event.item.id), event.item]
  })
  const turn = (text: string) =>
    new Promise<string>((resolve, reject) => {
      const timer = setTimeout(() => reject(new Error(`timed out: ${text}`)), 180_000)
      const subscription = manager.subscribe(id, (event) => {
        if (event.type === 'item' && event.item.kind === 'turn' && event.item.state === 'ended') {
          clearTimeout(timer)
          subscription.dispose()
          const reply = [...items].reverse().find((item) => item.kind === 'message' && item.role === 'assistant')
          resolve(reply?.kind === 'message' && reply.role === 'assistant' ? reply.text : '')
        }
      })
      void manager.prompt(id, [{ type: 'text', text }] as PromptPart[])
    })
  await turn('Remember the word APPLE. Reply OK.')
  await turn('Also remember the word BANANA. Reply OK.')
  const second = items.filter((item) => item.kind === 'message' && item.role === 'user')[1]
  await manager.rewind(id, second.id, false)
  const reply = await turn('List every word I asked you to remember, nothing else.')
  console.log('after rewind:', reply.replaceAll('\n', ' '))
  await manager.dispose()
  if (/banana/i.test(reply) || !/apple/i.test(reply)) throw new Error('the rewind did not take')
  console.log('REWIND SMOKE OK')
}

main().catch((error) => {
  console.error('REWIND SMOKE FAILED:', error)
  process.exit(1)
})
```
