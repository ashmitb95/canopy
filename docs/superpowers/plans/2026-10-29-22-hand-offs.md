**Goal:** *Hand off to…* moves a chat's work to the next step with the right agent.

What happens when you hand off:
1. You pick a task type (Research, Plan, Build, or Review).
2. AgentDeck starts a new chat on the same lane, with that task's default provider and mode.
3. It shows you a handoff prompt to edit.
4. Once you confirm, it sends the prompt.

**Nothing advances on its own.** Workflows are orchestration, not a view (decision 36): there are no stage tiles. The lane brief carries earlier chats, plan and notes.

**Architecture:**
- **Task types and their defaults** live in `.agentdeck/config.toml` as `[task.<id>]` tables, each with `label`, `provider` and `mode`.
- **When the config has no tasks**, the defaults are:
  - Research → Grok · Ask
  - Plan → Claude · Plan
  - Build → Codex · Accept edits
  - Review → Claude · Ask
- **A pure builder** writes the handoff prompt. It points the new chat at the previous chat's summary file when the chat is on a lane. Otherwise it quotes the previous chat's last reply.
- **Where to find it:**
  - the lane chip menu (*Hand off to…*);
  - a chat's context menu in the Sessions list;
  - the command palette, which hands off the active chat.

`src/lanes/tasks.ts`:

```ts
import { existsSync, readFileSync } from 'node:fs'
import { join } from 'node:path'
import type { PermissionMode } from '../core/types'
import { parseToml } from './toml'

export type TaskType = { id: string; label: string; provider: string; mode: PermissionMode }

export const DEFAULT_TASKS: TaskType[] = [
  { id: 'research', label: 'Research', provider: 'grok', mode: 'ask' },
  { id: 'plan', label: 'Plan', provider: 'claude', mode: 'plan' },
  { id: 'build', label: 'Build', provider: 'codex', mode: 'accept-edits' },
  { id: 'review', label: 'Review', provider: 'claude', mode: 'ask' }
]

const MODES = new Set<string>(['ask', 'accept-edits', 'auto', 'plan', 'full-access'])

/** Task types from `[task.<id>]` tables in `.agentdeck/config.toml`, or the defaults when none are complete. */
export function readTasks(root: string): TaskType[] {
  const path = join(root, '.agentdeck', 'config.toml')
  const data = existsSync(path) ? parseToml(readFileSync(path, 'utf8')) : {}
  const tasks = Object.entries(data).flatMap(([key, value]) => {
    if (!key.startsWith('task.') || typeof value !== 'object' || value === null) return []
    const { label, provider, mode } = value as Record<string, unknown>
    if (typeof label !== 'string' || typeof provider !== 'string' || typeof mode !== 'string' || !MODES.has(mode)) return []
    return [{ id: key.slice('task.'.length), label, provider, mode: mode as PermissionMode }]
  })
  return tasks.length > 0 ? tasks : DEFAULT_TASKS
}

export type HandoffInput = { task: string; from: string; lane?: string; summaryPath?: string; reply?: string }

/** The first prompt of the next chat; the user edits it before it is sent. */
export function handoffPrompt(input: HandoffInput): string {
  if (input.lane && input.summaryPath) {
    return `You are taking over lane ${input.lane} for the ${input.task} step. Start from the previous chat “${input.from}” (summary: ${input.summaryPath}) and the lane plan, then continue.`
  }
  const quoted = (input.reply ?? '')
    .trim()
    .split('\n')
    .map((line) => `> ${line}`)
    .join('\n')
  return `You are taking over from the chat “${input.from}” for the ${input.task} step. Its last reply was:\n\n${quoted}\n\nContinue from there.`
}
```

```ts
    vscode.commands.registerCommand('agentdeck.handOff', async (target?: SessionNode | string) => {
      const sourceId = typeof target === 'string' ? target : (target?.id ?? surfaces.activeSessionId())
      const source = sessionManager.list().find(({ record }) => record.id === sourceId)?.record
      if (!source) return void vscode.window.showInformationMessage('Open a chat to hand off from.')
      const tasks = readTasks(root ?? '')
      const task = await vscode.window.showQuickPick(
        tasks.map((candidate) => ({
          label: candidate.label,
          description: `${providers.get(candidate.provider)?.label ?? candidate.provider} · ${candidate.mode}`,
          task: candidate
        })),
        { placeHolder: `Hand off “${source.title}” to…` }
      )
      if (!task) return
      if (!providers.has(task.task.provider)) {
        return void vscode.window.showErrorMessage(`No provider “${task.task.provider}”. Check [task.${task.task.id}] in .agentdeck/config.toml.`)
      }
      const summary = source.laneId && memory ? join(memory.laneDir(source.laneId), 'chats', `${source.id}.md`) : undefined
      const text = await vscode.window.showInputBox({
        prompt: `First prompt for the ${task.task.label} chat (edit before sending)`,
        value: handoffPrompt({
          task: task.task.label,
          from: source.title,
          ...(source.laneId ? { lane: source.laneId } : {}),
          ...(summary && tracker ? { summaryPath: relative(tracker.root, summary) } : {}),
          reply: sessionManager.lastReply(source.id)
        })
      })
      if (!text?.trim()) return
      const next = await sessionManager.create(task.task.provider, task.task.mode)
      if (source.laneId) await sessionManager.setLane(next.id, source.laneId)
      surfaces.openPanel(next.id)
      await sessionManager.prompt(next.id, [{ type: 'text', text: text.trim() }])
    }),
```
